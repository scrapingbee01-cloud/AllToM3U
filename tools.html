Rules

Replaces all occurrences in the whole text. Case-sensitivity follows “Ignore case”.

Leave empty to delete matches.

Examples: [ … ], ( … ), { … }, or any start/end markers.

By default, both xxxxx and yy are kept and only the text between them is removed.
